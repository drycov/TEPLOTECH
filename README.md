# TEPLOTECH EVP-6

Прошивка локального контроллера отопления на Arduino. Контроллер показывает четыре температуры, управляет тремя ступенями нагрева и циркуляционным насосом через LCD 20×4 и аналоговую клавиатуру.

## Режимы

- **AUTO** — задаёт температуру воды по наружной температуре с использованием погодозависимой таблицы.
- **MANUAL** — включает выбранные ступени нагрева с термостатическим отключением по заданной температуре.
- **STOP** — после включения питания контроллер всегда стартует остановленным. Оператор должен явно снять STOP кнопкой LEFT на главном экране.
- Нагрев блокируется при недостоверном датчике воды на выходе, а в AUTO — также при ошибке наружного датчика.
- Программный предел нагрева — 85 °C. Это ограничение в прошивке, а не замена независимого термостата или аварийной защиты оборудования.
- Насос включается по сохранённой настройке; при активном нагреве он принудительно включён.

## Подключения, сохранённые из исходного проекта

| Функция | Пины |
|---|---|
| Нагреватели A/B/C | D3 / D4 / D5 |
| Насос | D6 |
| Аналоговая клавиатура | A3 |
| Датчики: помещение / улица / вход воды / выход воды | A1 / A2 / A6 / A7 |
| LCD 20×4, I²C | адрес 0x27 |

Выходы реле активны низким уровнем, как в исходном коде. Перед подключением силовых цепей проверьте полярность модулей реле и распиновку конкретной платы. A6/A7 доступны не на всех моделях Arduino.

## Клавиатура

На главном экране LEFT переключает STOP/RUN, в MANUAL кнопки UP/DOWN меняют сохранённую заданную температуру, OK открывает меню. В меню UP/DOWN выбирают пункт; OK подтверждает, LEFT возвращает назад.

Настройки хранятся в EEPROM как запись фиксированного формата с версией и CRC. Старые или повреждённые данные заменяются настройками по умолчанию.

## Зависимости

- Arduino EEPROM
- GyverNTC
- LiquidCrystal_I2C

Ethernet-библиотека из прежнего исходника удалена: сетевое управление в нём не было реализовано, а протокол и требования к нему не определены.
