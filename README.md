# TEPLOTECH EVP-6

Прошивка локального контроллера отопления на Arduino Nano или ESP32. Контроллер измеряет четыре температуры, управляет тремя ступенями нагрева и циркуляционным насосом. На выбор доступны LCD 20×4 по I²C и монохромный OLED 128×64 диагональю 0,96″.

## Режимы и защиты

- **AUTO** — задаёт температуру выходящей воды по наружной температуре с использованием исходной погодозависимой таблицы.
- **MANUAL** — включает выбранные ступени нагрева с термостатическим отключением по заданной температуре.
- **STOP** — после каждого включения питания контроллер стартует остановленным. Оператор снимает STOP кнопкой LEFT на главном экране.
- Нагрев блокируется при недостоверном датчике выходящей воды, а в AUTO — также при ошибке наружного датчика.
- Ступени AUTO переключаются с интервалом 5 секунд и гистерезисом 2 °C.
- Программный предел воды — 85 °C. Это ограничение прошивки, а не замена независимого аварийного термостата.
- Насос включается по сохранённой настройке; при включённых нагревателях он принудительно включён.
- Настройки хранятся в EEPROM с версией записи и CRC.

## Платы и подключения

| Функция | Arduino Nano (ATmega328P) | ESP32 DevKit |
|---|---:|---:|
| Нагреватели A/B/C | D3 / D4 / D5 | GPIO25 / GPIO26 / GPIO27 |
| Насос | D6 | GPIO14 |
| Аналоговая клавиатура | A3 | GPIO36 |
| Датчик помещения | A1 | GPIO32 |
| Датчик улицы | A2 | GPIO33 |
| Входящая вода | A6 | GPIO34 |
| Выходящая вода | A7 | GPIO35 |
| I²C SDA/SCL | A4 / A5 | GPIO21 / GPIO22 |

Релейные выходы активны низким уровнем, как в исходной схеме. Для ESP32 используйте входные цепи, совместимые с логикой 3,3 В; на GPIO датчиков нельзя подавать 5 В. Убедитесь, что делитель NTC рассчитан на напряжение питания выбранной платы. GPIO36 ESP32 — вход только, для аналоговой клавиатуры требуется внешняя лестница резисторов.

## Дисплеи

- **LCD 20×4 I²C** — адрес 0x27.
- **OLED 0,96″ SSD1306 128×64 I²C** — адрес 0x3C по умолчанию; для 0x3D задайте `TEPLOTECH_OLED_I2C_ADDRESS=0x3D`.
- Для OLED с контроллером SH1106 добавьте `-DTEPLOTECH_OLED_SH1106=1` в `build_flags`. OLED использует постраничный буфер, чтобы сохранить SRAM Nano.

На ESP32 используются аппаратные I²C GPIO21/GPIO22, на Nano — стандартные SDA/SCL A4/A5.

## Сборка PlatformIO

Из корня репозитория:

```sh
pio run -e nano-lcd
pio run -e nano-oled
pio run -e esp32-lcd
pio run -e esp32-oled
```

Для Nano с новым загрузчиком замените `nanoatmega328` на `nanoatmega328new` в двух Nano-окружениях. Файл `TEPLOTECH.ino` остаётся доступен для Arduino IDE; PlatformIO использует обёртку `src/main.cpp`.

## Клавиатура

На главном экране LEFT переключает STOP/RUN, в MANUAL кнопки UP/DOWN меняют заданную температуру, OK открывает меню. В меню UP/DOWN выбирают пункт; OK подтверждает, LEFT возвращает назад. В редакторе ступеней UP/DOWN выбирают нагреватель, OK переключает его.

## Зависимости

- Arduino EEPROM и Wire
- GyverNTC
- LiquidCrystal_I2C
- U8g2 (OLED)

Сетевое управление не включено: Ethernet-заголовок в исходном проекте не сопровождался сетевым сервисом или описанием протокола.
